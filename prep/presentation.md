# Presentation Plan

## Hook
* Ever forget about a test coming up or realize an assignment is due at the last minute? Staying organized in school can be stressful, especially when you have multiple classes. What if one app could help you keep track of it all?

## Product
* My Student Success App helps students stay organized by keeping track of assignments and upcoming tests. Users can add assignments with due dates, and the app automatically creates a list sorted by the closest due date first. It also shows upcoming tests so students can prepare ahead of time.

It acts like a personal school organizer that helps students manage their time and avoid missing important deadlines.


## Process
* Wireframe Example: Show the wireframe of my project because it helped me plan the layout and organize where each feature would go before building the app.

* MVP: What I did:
  * Created a section where users can add assignments
  * Added due dates for assignments
  * Made the app automatically sort assignments by due date
  * Added an upcoming tests section

* Beyond MVP:
  * Mark tasks as done - let students remove finished assignments and tests.
  * Subtasks for exams - help students write what they need to learn

* Code snippets of:
  * How assignments were added to the list
  * How due dates were compared and sorted
  * How upcoming tests were displayed on the page
  * Challenge - one challenge was making sure assignments were listed in the correct order by due date. Another challenge was keeping the app simple while still being useful for students.

## Conclusion
* [Here is a video of project](https://drive.google.com/file/d/1J9DfwWUhtm8GL3jESqdmbnOhVSuk_OID/view)
* Takeaways
   * User experience is important: Keeping the app clean and easy to use makes students more likely to actually use it.
   * Problem-solving is part of coding: Figuring out how to sort assignments correctly and display them clearly helped me improve my coding skills.
   * Planning saves time: Making a wireframe first helped me organize my ideas before starting the code.
   * Projects can always grow: Starting with core features gave me a strong base, and I can always add more tools in the future like reminders, grade tracking, or study schedules.
   * Technology can help students succeed: This project showed me how coding can be used to create tools that make school less stressful and more manageable.
